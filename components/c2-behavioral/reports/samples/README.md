# C2 Trajectory Sample Envelope

This directory contains sample engagement trajectory records exported from Component 2.
Synthetic student PIDs (STU_XXXXXXXX) are derived from OULAD and do not correspond to real LMS students.
The records are sourced from the OULAD test split (presentation 2014J) across courses and weeks.
Trajectory labels (stable, improving, declining, volatile) are generated by the C2 HistGradientBoosting model.
The confidence score represents the raw maximum class probability and is uncalibrated.
Five additional synthetic records demonstrate the fallback rule for dormant students.
